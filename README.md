# LXC Hosting Self-Hosted is now Boukarou

This project was rewritten from scratch and renamed **[Boukarou](https://github.com/KmerHosting/boukarou)**.

Boukarou is the free, open-source edition of [KmerHosting LXC](https://lxc.kmerhosting.com). It has the same container features, with no billing:
- user accounts with per-user limits, each one optional;
- SSH and a root web terminal;
- snapshots, metrics and traffic quotas;
- custom domains with HTTPS.

Install it on Ubuntu 22.04/24.04/26.04:

```bash
curl -fsSL https://raw.githubusercontent.com/KmerHosting/boukarou/main/deploy/install.sh | sudo bash
```

This repository is no longer maintained. Please open issues and pull requests on [KmerHosting/boukarou](https://github.com/KmerHosting/boukarou).
